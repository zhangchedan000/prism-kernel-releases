# Prism 指纹内核

[指纹浏览器](https://github.com/zhangchedan000/fingerprint-browser) 使用的 Prism 指纹内核，基于 ungoogled-chromium，Windows x64。

- 每个内核版本（prism8、prism9……）是一个发行版，里面有 Chromium 156 和 155 两个内核 zip 和 SHA256SUMS。
- 一般不用手动下载：在指纹浏览器的「内核管理 → 在线下载内核」里一键安装和更新。
- 手动安装：下载 zip 解压，在「内核管理 → 导入本地内核」里选解压出来的 `chrome.exe`。

指纹浏览器（启动器）的安装包在 [fingerprint-browser 的发行版](https://github.com/zhangchedan000/fingerprint-browser/releases)。prism8 及更早的内核也还保留在那里。
